# BaziKhooneh

BaziKhooneh is a collection of familiar multiplayer games for everyone.

The app provides a polished visual interface comparable to conventional games,
while also being fully accessible to blind and low-vision players. Sighted and
blind players can share the same experience and play together.

## First Game

The first game in development is classic **3×3 Tic-Tac-Toe**.

## Status

This project is currently under development.
